# Smokys Launcher

Launcher oficial para la beta de Smokys para Windows x64.

## Descargar

Entrá en [la última versión](https://github.com/crysmajul/smokys-launcher/releases/latest) y descargá el ZIP **SmokysLauncher-…-PaqueteUnico.zip**.

Extraé el ZIP completo y abrí **SmokysLauncher.exe**. Conservá launcher.json y los textos junto al ejecutable. Elegí la carpeta del juego y pulsá Instalar. Si ya lo tenés instalado, elegí su misma carpeta.

Esta entrega se descarga una sola vez. Al abrirlo, el launcher recibe sus próximas actualizaciones desde GitHub y los parches del juego desde Google Drive. Las partidas y ajustes se conservan. Tras una actualización correcta se eliminan las versiones anteriores y los temporales.

No requiere instalar .NET ni WinRAR. Google Drive puede limitar temporalmente las descargas del juego.

## Archivos de cada versión

- **SmokysLauncher-…-PaqueteUnico.zip**: descarga completa para jugadores.
- **package.zip** y **latest-launcher.json**: usados por la actualización automática.

Este repositorio aloja las descargas del launcher; no contiene el código fuente ni credenciales del desarrollador.
